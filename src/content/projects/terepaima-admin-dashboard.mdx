## Legacy modernization

**Inmobiliaria Terepaima** depended on a legacy **Microsoft Access** system: slow, error-prone, and tied to a single physical location.

I led migrating that system to a modern **web platform**, redesigning the database from the ground up to support the administrator’s growth.

As **Software Engineer**, I built the **Angular** frontend and **NestJS** backend so the team can manage **multiple buildings** concurrently from any device. Response times and data integrity improved dramatically, removing the concurrency limits the admin staff hit before.

## Data model and operations

The hardest part was extracting and cleaning business logic trapped in Access. I designed a scalable **MongoDB** model that organized decades of financial and owner records in a flexible, fast structure.

Day-to-day bottlenecks disappeared: tasks that took minutes on the old database now complete in milliseconds thanks to **Node**’s async model and NestJS.

The **Angular** admin dashboard surfaces delinquency and cash flow in one place—something the legacy stack could not visualize holistically.

## TanStack Query on the client

On Angular I used **TanStack Query** instead of relying only on RxJS for server state. That simplified fetching, added caching, and made navigation between buildings and apartments feel instant.

The UI uses **optimistic updates** for payments and expenses so staff rarely block on server round-trips.

## NestJS and MongoDB

The backend is a **modular monolith** in NestJS—maintainable and quick to extend.

It handles **multi-currency** financial flows, payment reconciliation, and **monthly statements** generated automatically as PDFs. **MongoDB** fits the dynamic shape of real-estate data so each condominium can have custom configuration without painful relational migrations.

## Impact

Automating month-end close and bulk receipt generation cut administrative processing time by **more than 60%**. As a native web app, there is no on-prem server to babysit—the team can work remotely or from any office with a secure connection.
